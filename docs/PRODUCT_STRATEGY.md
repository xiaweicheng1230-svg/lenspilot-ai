# Product Strategy

## Wedge

The entry point is a single, concrete question: “How should I take the next shot?” A structured diagnosis supports that answer, while history and learning plans turn one-off analysis into retention.

## Value loop

Upload → diagnose → try the next-shot settings → upload again → compare → build a profile → receive targeted practice.

## Success signals

- Users reach a complete report after uploading a valid photo.
- Users interact with the next-shot recommendation.
- Users return with another photo from a similar scenario.
- Feedback indicates that advice was understandable and executable.

No product metrics will be presented as achieved until real usage data exists.
