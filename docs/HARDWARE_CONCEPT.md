# LensPilot Hardware Concept

This document describes a future product concept, not implemented hardware.

## Concept

A small photography companion with a display, ESP32-class connectivity controller, BLE, Wi-Fi, USB-C, and an SD reader. It could import a recent photo, display concise AI guidance, show camera-setting trade-offs, and present field assignments.

## Validation before building

The Web MVP should first validate whether photographers use next-shot advice while they can still reshoot. Hardware work should start only after the workflow, acceptable latency, privacy model, power budget, and camera compatibility assumptions have evidence.
